# 🏙️ Экономический Кликер: Монаполис

**Браузерная кликер-игра на Vue.js с глубокой экономической механикой**

## 🎮 Основные Функции

### 💰 Базовая Механика
- **Клик** - основной источник дохода
- **Здания** - генерируют пассивный доход
- **Модификаторы** - усиливают доход и клик
- **Престиж** - перезагрузка с постоянным множителем

| Здание | Стоимость | Доход | Описание |
|--------|-----------|-------|----------|
| 🍋 Ларек | $10 | $1.5/сек | Первый источник |
| 🥖 Пекарня | $80 | $6/сек | Среднее производство |
| 🏪 Магазин | $400 | $12/сек | Розничная торговля |
| 🏢 Офис | $1.5k | $30/сек | Консалтинг |

| 🛒 Торговый центр | $200k | $600/сек | Огромный комплекс |
| 🏦 Банк | $500k | $1.5k/сек | Финансовые услуги |

### ⚡ Модификаторы (11 видов)

**Усиление клика:**
- 💪 Сильные пальцы: +$1/клик
- 🔥 Мощный хват: +$5/клик
- ✨ Золотая рука: +$20/клик

**Общий доход:**
- ⚡ Эффективность труда: +20%
- 📢 Маркетинг: +30%
- 💻 Технологии: +50%

**Специализированные:**
- 🥐 Свежая выпечка: +100% (пекарни)
- 🛍️ Розничная сеть: +150% (магазины)
- ⚙️ Промышленный бум: +100% (фабрики)
- 🎨 Архитектурный шедевр: +80% (небоскребы)

### 🎯 Система Достижений (11)
- 🖱️ Первый клик
- 🏗️ Строитель - постройте здание
- 🏛️ Архитектор - 10 зданий
- 💰 Миллионер - $1M
- 🏙️ Мастер города - 50 зданий
- 👑 Миллиардер - $1B
- 🎯 Коллекционер - все здания
- 💵 Пассивный доход - $1k/сек
- 🔄 Начало заново - используйте престиж
- 🎓 Мастер апгрейдов - все модификаторы
- 😴 Ленивый миллионер - $1M от пассивного дохода

### ✨ Система Престижа
- Перезагрузка прогресса за вознаграждение
- Постоянный множитель: +10% за уровень
- До 100 уровней престижа
- Требуемая сумма: $10M

### 🏆 Дополнительные Функции
- **Таблица лидеров** - топ-10 результатов
- **Клавиатурные управления** - пробел + 1-9
- **Экспорт/Импорт** - резервные копии
- **Светлая/Темная тема** - переключение
- **Автосохранение** - каждые 5 секунд
- **Визуализация города** - иконки зданий

## 📊 Баланс Игры

**Прогрессия затрат на здания:**
- Каждое следующее здание того же типа дороже на 15%
- Вычисляется по формуле: `baseCost * 1.15^count`

**Множители доходов:**
- Клик = 1 + бонусы + 10% от пассивного дохода
- Пассивный = сумма(здания * множители)

**Престиж:**
- Множитель: 1.1x за уровень
- Порог: $10M
- Макс. уровень: 100

## 💾 Сохранение

Игра автосохраняется каждые 5 секунд в `localStorage`.

**Что сохраняется:**
- Все деньги и здания
- Купленные модификаторы
- Разблокированные достижения
- Уровень престижа
- Визуализация города

**Экспорт:**
- Кнопка "📥 Экспорт" скачивает JSON файл
- Можно хранить на компьютере

**Импорт:**
- Кнопка "📤 Импорт" загружает JSON файл
- Восстанавливает полный прогресс
